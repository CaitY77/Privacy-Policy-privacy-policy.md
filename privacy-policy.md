# Cahit Log — Privacy Policy

**Last Updated:** October 13, 2026

## 1. Introduction
Cahit Log is a Discord moderation and logging bot designed to help server administrators monitor server activity and maintain security.

## 2. Data We Process
Depending on enabled features, Cahit Log may process:

- Discord user, server, channel, and role IDs
- Member join and leave events
- Message deletion and editing events
- Message content and changes to message content
- Role assignments and permission changes
- Voice channel join, leave, and movement events
- Moderation events, including bans, kicks, and timeouts
- Channel and server configuration changes
- Event timestamps and relevant audit log information

## 3. How We Use Data
Data is processed to generate moderation logs, identify server activity, support administrators, and improve server security.

## 4. Data Storage and Retention
Logging information may be sent to designated Discord log channels. Additional storage, if enabled, depends on the bot's configuration. Data retention periods and deletion procedures should be documented according to the bot's actual implementation.

## 5. Data Sharing
Cahit Log does not sell personal data. Information may be accessible to authorized server administrators and infrastructure providers necessary to operate the service.

## 6. Data Deletion
Users and server administrators may contact the bot developer to request information about stored data or its deletion, subject to applicable requirements and Discord permissions.

## 7. Security
Reasonable technical and organizational measures are used to protect processed information.

## 8. Changes
This policy may be updated when bot features or data practices change.

## 9. Contact
For privacy inquiries, contact the Cahit Log developer through the bot's official support contact.
